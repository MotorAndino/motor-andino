# Motor Andino — versión para GitHub Pages

## Publicar gratis

1. Crea una cuenta en GitHub.
2. Crea un repositorio público llamado `motor-andino`.
3. Sube todos los archivos y carpetas de este paquete al repositorio.
4. En GitHub entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Elige la rama `main` y la carpeta `/ (root)`.
7. Guarda. GitHub Pages publicará el sitio en una dirección similar a:
   `https://TUUSUARIO.github.io/motor-andino/`

## Antes de enviar el sitio a Google

Reemplaza `TUUSUARIO` en:
- `robots.txt`
- `sitemap.xml`

por tu usuario real de GitHub.

Después conecta el sitio con Google Search Console y envía:
`https://TUUSUARIO.github.io/motor-andino/sitemap.xml`

## Archivos principales

- `index.html`: portada.
- `categorias/`: páginas temáticas.
- `articulos/`: primeros artículos de ejemplo.
- `assets/css/style.css`: diseño.
- `assets/js/main.js`: JavaScript básico.
- `robots.txt`: instrucciones para rastreadores.
- `sitemap.xml`: mapa del sitio.
- `404.html`: página de error.
- `.nojekyll`: evita procesamiento innecesario de Jekyll.

## Importante

Los artículos son demostrativos. Para posicionar en Google conviene publicar contenido original, profundo, verificado y actualizar el sitemap al agregar nuevas páginas.
